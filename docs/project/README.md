# Project records

These documents record how the lab was planned, built and checked. The lessons do not depend on them. Start with the [learning guide](../LEARNING_GUIDE.md) and use these files when you want to see where a piece of evidence came from.

| Record | Use it to |
| --- | --- |
| [Final report](FINAL_REPORT.md) | Read a synthesis of what the experiments taught across all nine lessons |
| [Implementation plan](IMPLEMENTATION_PLAN.md) | See the original scope, milestones and acceptance criteria |
| [Progress record](PROGRESS.md) | Separate implemented code, completed training, evaluated behavior and reproduced artifacts |
| [Conformance map](CONFORMANCE.md) | Trace each requirement to its evidence and stated limitations |
| [Code-review case study](CODE_REVIEW.md) | Study how reviewing the evaluator changed what the evidence could support |
